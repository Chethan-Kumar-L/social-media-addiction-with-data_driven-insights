# 📱 Student Social Media Addiction & Wellness Analysis (Python)

## 🎯 Objective
Explored student social media usage patterns and demographic influences to uncover behavioral trends and guide data-driven digital detox programs.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Manipulation:** `Pandas`, `NumPy`
* **Visualization:** `Matplotlib`, `Seaborn`

## 📊 Core Tasks & Implementation
* **Data Cleaning & Preprocessing:** Handled missing values, formatted data types, and prepared multi-attribute student datasets.
* **Feature Engineering:** Built custom Python functions using conditionals (`if-else`) to classify student risk levels (Low/Medium/High) based on daily usage hours.
* **Aggregations:** Leveraged Pandas `groupby` operations to evaluate average addiction levels across genders, age groups, and education levels.
* **Visualizations & Storytelling:** Developed 4 distinct chart types (Bar, Pie, Heatmap, Line plot) complete with data insights and a 10-line executive story summary.
